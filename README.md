## Proyecto destacado

**Asistente de voz en Raspberry Pi 5** · *en curso*

Asistente de voz casero que corre por completo en una Raspberry Pi 5, con pantalla táctil y control de luces inteligentes.

- Backend en Python con API local (FastAPI y WebSocket)
- Interfaz en PySide6 / QML
- Control de dispositivos Tuya con tinytuya
- Desarrollo por etapas, probando cada módulo primero en entorno local
